# Startpage

## Mode

Operate: open a useful link quickly, check a station board, or see the live rail map at a glance.

## Approved concept

Use the approved personal startpage comp at `.impeccable/mocks/personal-startpage.png`. The personal links and WORK area lead; the station board and map are secondary. Keep the industrial brutalist styling in the typography, geometry, and signal details. Do not expand this into a control-room dashboard.

## Content and states

- Editable personal categories and bookmarks, with a dedicated WORK category.
- Selected SNCB station, departure/arrival tab, compact timetable, update state.
- Live Belgian rail map with network tracks and live train positions.
- Admin edit mode, light/dark theme, save state, loading/error/empty states.
- Responsive desktop and mobile layouts, keyboard and reduced-motion support.

## Signature interaction

Edit mode exposes inline add/edit/delete/reorder controls. The station selector changes the board without leaving the page; map markers update from the source snapshot.
